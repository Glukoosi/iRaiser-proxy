How to use

      
    
        
  1. Open your fundraiser page on the charity's iRaiser site (for example oma.wwf.fi) and copy its address from the browser.
    2. 
        
  2. Paste the address above and press Get URL.
    3. 
        
  3. Use the API URL wherever you need the numbers. It returns:
          
    {
  "target_amount": 5000,      // goal in euros, 0 if none
  "total_amount": "4159.02"   // raised so far, as a string
}
    
        
    4. 
        
  4. Poll it as often as you like; results refresh every 5 seconds. For example:
          
    const res = await fetch(API_URL);
const { total_amount } = await res.json();
    
        
    5. 
      

      
The fundraiser page must be public. Private or removed fundraisers can't be looked up.
